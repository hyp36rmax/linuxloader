AER-04 records passive original-game vehicle evidence beside native steering requests.

Place the verified DVP-0015A Jennifer executable beside this package and run
Run-AER04-FFB-Telemetry.cmd once. No environment configuration is required.

The observer records only verified fields: derived front-tire direction, aggregate
and front-tire road masks, the preserved threshold state, callback boundaries,
and original logical steering requests. Unknown vehicle identity, speed, raw
steering input, orientation, wall state, and vehicle-contact state remain explicit
unavailable values. Nothing is sent to physical steering or motion hardware.
